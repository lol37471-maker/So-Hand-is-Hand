This mod make you can use mouse right and left in same time withing offhand's things and mainhand's things.
using shield in offhand, you can still attacking mob with mainhand's weapon or breaking blocks with pickaxe.
(may compatible with most mods，like the shields and bow/crossbow from: Tetra, Cataclysm, Twilight Forest)

你可以双手同时使用不同的物品，你可以按住右键举盾的同时，使用左键进行攻击。
当然，也可以把副手的物品改成：食物，弓，弩等右键物品。
目前可以兼容大部分模组的盾牌和弓弩，列如tetra，灾变，暮色。
